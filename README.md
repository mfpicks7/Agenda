# Agenda

Mi Agenda: aplicación Android local para actividades de Trabajo y Personal.

[Descargar APK de prueba](https://github.com/mfpicks7/Agenda/actions/runs/38688141414/artifacts/11951730004) · [Guía de instalación y uso](GUIA_MI_AGENDA.md) · [Resultados de verificación](VERIFICACION.md)

Análisis sin incidencias, 11 pruebas Flutter correctas y arranque/reapertura comprobados en emulador Android 35. Dentro del ZIP de descarga está `Mi-Agenda-debug.apk`.

Esta primera versión incluye calendario, actividades, notas y checklist persistentes. Repeticiones y recordatorios quedan para las siguientes entregas.

Versión **1.0.1 (2)**: icono MF proporcionado por el usuario, con recursos por densidad e icono adaptable Android.
