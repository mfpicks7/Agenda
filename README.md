# Agenda

Mi Agenda: aplicación Android local para actividades de Trabajo y Personal.

[Descargar APK de prueba](https://github.com/mfpicks7/Agenda/actions/runs/38751233453/artifacts/11981647476) · [Guía de instalación y uso](GUIA_MI_AGENDA.md) · [Resultados de verificación](VERIFICACION.md)

Análisis sin incidencias, 21 pruebas Flutter correctas y arranque/reapertura comprobados en emulador Android 35. Dentro del ZIP de descarga está `Mi-Agenda-debug.apk`.

Esta primera versión incluye calendario, actividades, notas y checklist persistentes. Repeticiones y recordatorios quedan para las siguientes entregas.

Versión **1.0.1 (2)**: icono MF proporcionado por el usuario, con recursos por densidad e icono adaptable Android.

Versión **1.0.2 (3)**: calendario compacto según la referencia del usuario, mes completo visible, puntos por categoría y lista detallada debajo. El botón de crear queda fuera del calendario.
